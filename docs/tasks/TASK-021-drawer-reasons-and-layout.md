## 实施报告

### 实现

- `ContextDrawerRowView.cs` 集中处理名称/分数/推荐标记/理由展开；`ContextDrawer.cs`
  管理单项展开、句柄隔离及自适应滚动。名称省略但悬停完整显示，分数独立对齐；推荐同时
  使用金色边缘、标记与背景。路线按钮使用“均衡/生存/成长”，悬停保留完整偏好名。
- `AdviceReasonReader.cs` 从已验证候选提取有限非零贡献的消息，稳定排序、去重、至多
  三条及长度限制；卡牌/路线/通用 adapter 共用。没有模型、网络、权重或协议变化。
- `advisor/route.py` 仅给已有风险因子补消息，区分遭遇池估计与已知 Boss，不显示为胜率
  或分数加减明细，也不声称这些片段是完整策略解释。
- `GenericAdviceController.cs` 复用已有 BackendLiveness/AdviceFileReader，先检查后台
  再读缓存，失活撤下建议；读失败后允许同时间戳重试。此变化不替代扩展真机回归。
- `AdviceAvailability.cs` 忽略不可选项，避免售罄项的 null 分数错误影响其他有效建议。
  Context Drawer 按各行已验证数值渲染，不因屏级提示抹掉仍有效行。
- Guide/Mod、兼容清单、示例、安装配置及 README 同步至 `0.3.8-alpha.0 / 0.3.8`；
  fingerprint `d8013e41a9638f8251505a2a0c60d0077ccbde49a0f6b2ee235a867d7fd1abba`。
  事件 v9、SQLite v8、tag v6、策略权重和 capability 不变。
