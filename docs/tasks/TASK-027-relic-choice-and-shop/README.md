## 背景（2026-10-28 盘点）

- Neow 与七位古神提供的选项全部是遗物（`AncientEventModel.RelicOption<T>`，共 102 个；
  奥罗巴斯的“铁甲战士／静默猎手……”选项是对应角色的海玻璃）。用户指出 Neow 还有删牌等选择：这些都是遗物的**拾起效果**。
- 牌组引擎此前把只有拾起或局外钩子的遗物记为 `irrelevant`、`mechanics` 为空：对已拥有的遗物这是对的
  （拾起的改动已在牌组里），但用来**选**遗物时会把精密剪刀（删 1 张牌）、金珍珠（150 金币）等估成 0 且不报缺口。
  102 个古神遗物中 58 个有 `AfterObtained`，其余多有战斗结束、篝火、卡牌奖励、地图等局外钩子。
- 商店现状：卡牌仍走旧版选牌评分（含社群先验，与 2026-10-22 取消社群评价的决定不符）；遗物按标签固定加分；
  药水只认鲜血药水；移除用旧经验规则。能力开关为 `pending_validation`，游戏内不显示。
- 历史数据（用户 125 局）：古神遗物选择 97 次（选项与选择齐全）；商店 136 次（货架、购买、花费齐全，单价未记，
  价格公式可从程序集读出：普通/罕见/稀有牌 50/75/150，无色 ×1.15，再经 `CalcCost`）；生命记录 699 场战斗。
