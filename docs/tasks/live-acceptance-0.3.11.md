发现：

1. **遗物协同误标（缺陷）**：发行 SQLite 中遗物的 116 个 `supports_*` 标签（100 件遗物）全部来自
   `description_rule` 文本匹配。实测战纹涂料（拾起时升级 2 张技能）被标 `supports_skill`，斗篷扣
   （回合结束按手牌数获得格挡）被标 `supports_block`，使挑衅获得 `relic_synergy +4.0` 并排第一。
   违反“理由不得引用当前局不存在的事实”与禁止宽泛文本匹配。
2. **跳过分偏低**：同屏跳过 40.7。部分由发现 1 连锁造成（最强候选局面分被抬过 56，触发
   `useful_candidate -6`）；修复发现 1 后复评，剩余部分如仍偏低记为策略反例，不以调权重掩盖。
