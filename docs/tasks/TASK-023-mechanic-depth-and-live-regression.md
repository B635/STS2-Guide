## 机制事实与具体实施确认

- 完美打击：本机程序集`PerfectedStrike`的真实谓词为CardTag.Strike，倍率取玩家战斗
  AllCards，含Hand/Draw/Discard/Exhaust/Play；基础6、每张2、升级每张增加1，自身也是
  Strike。目录22个Strike稳定ID与当前程序集分类逐一吻合；不以卡名匹配。非战斗原生
  CalculatedVar乘数为0，所以不能从奖励屏显示的6推断永久牌组加成不存在。本任务只估算
  永久牌组加入候选后的基准，不预测临时生成/移除、力量或敌人状态。
- 药水切片限BLOOD_POTION：当前程序集HealPercent=20、AnyTime，OnUse按最大HP百分比
  调用CreatureCmd.Heal。已核对商店非战斗无治疗倍率Hook，截断并封顶，计算
  min(max_hp-hp,floor(max_hp*20/100))。数值通过精确ID已验证静态标签进入现有SQLite
  效果表，标签v7；只估计当前恢复机会，不将购买当成饮用，也不计未来储备或战斗联动。
  满血恢复机会为0不伪造通用收益，缺HP/非法参数/槽位未知保持缺口。不能启用其他药水。
- 数据分工：Strike Agent维护发行卡牌必要tags/vars保留；Merchant Agent维护已验证药水
  标签和EFFECT_TAG_VERSION。root整合版本和构建，两者不并行修改同一数据文件。
