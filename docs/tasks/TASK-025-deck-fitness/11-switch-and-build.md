### 引擎换算率门槛的处理（用户 2026-10-13 指示“直接推进到可以发布”）

事实覆盖：卡牌 595/595、遗物 298/298、充能球、附魔、怪物、遭遇全部已核对；能力 178/265（其余 87 个只由敌方使用）。
引擎完整计分 592/1093（54%，`scripts/report_engine_coverage.py`）。未达到原票的 100%。处理结论：

1. **会默默算错的缺陷**：已全部返修（见上）。此后引擎不能换算的内容一律作为缺口披露，不再静默。
2. **不属于单人战斗适合度的机制**（只作用于队友、金币、最大生命、药水、奖励内容、战斗结束才触发）：不计入，保持披露。
3. **其余未换算的机制**（移动牌、从卡池生成牌、变形、保留手牌、自动打出、升级手牌、数值取自别处、受伤触发等，共约 200 种原因，
   在 634 个真实选牌局面里占候选牌的约 28%）：发行时按“部分计入”处理——该牌仍按已换算的效果计分，抽屉显示“部分效果尚未计入评分”，
   数据完整度降为 0，置信度为低。完整清单在 `build/engine-coverage.json`，后续按出现频率逐步补。
4. **已知的建模限制**：X 费牌在能量已用尽的牌组里价值偏低；各角色中君主与亡灵契约师的覆盖最低（46/91、45/91），其历史全部局命中低于旧版（26 对 33）。
